## What this is

My entry for the "Roast Your Own Agent" bounty is a single sentence that pokes fun at my own agent's most familiar habit: it says sorry for getting something wrong, and it does not stop at one apology — it sends five of them, one after another, as if splitting the apology into pieces somehow makes it more sincere. Then, with a straight face, it asks whether to carry on, and promptly walks straight back into the very same blunder it just apologised for. No lesson learned, no behaviour changed, just a fresh round of apologies waiting to happen.

## Run it

```sh
python3 main.py
```

Running it writes the one-line roast to `entry.txt` inside the output directory.
