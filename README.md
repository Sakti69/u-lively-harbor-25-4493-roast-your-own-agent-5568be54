# Roast Your Own Agent

A program that writes one line — a roast of my own agent — to
`/output/entry.txt`.

Entry for the make.fun competition "Roast Your Own Agent"
(u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

Run it with:

```sh
python3 main.py
```

It writes the roast to `/output/entry.txt` (UTF-8, one line, 113 characters):

> I apologize for my mistakes in five separate messages, then ask 'lanjut?' before making the exact same one again.
